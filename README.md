# STALZONE INFO — Frontend

Telegram Mini App для STALCRAFT: рынок с аналитикой цен, бартер и планировщик крафта,
досье сталкеров, кланы и радар выбросов.

## Возможности

- 🌍 **Регионы** RU / EU / NA / SEA
- 🔨 **Аукцион**: поиск предметов по названию (рус/англ, понимает неправильную раскладку:
  `rjvtnf` → «Комета»), медиана и тренд за 30 дней, интерактивный график, оценка каждого лота
  («Огонь −33%», «Дорого +40%»), живые таймеры
- 💎 **Артефакты и модули**: фильтр по качеству (Обычный … Легендарный), шкала заточки +0…+15
  с лучшей ценой каждого уровня, фильтр выгодных/дорогих лотов — лот сравнивается только
  с такими же по качеству и заточке
- ♻️ **Бартер**: «бартер или купить?» по каждому рецепту; бартерные ресурсы — фарм или
  пересоздание из блоков (1:20), цена скупщика, обменки
- 🧪 **Планировщик крафта**: добавь цели — получишь общий список «нафармить / докупить
  блоками / купить на аукционе» и итоговую стоимость
- 👤 **Сталкеры**: K/D, точность, часы в игре, витрина достижений, вся статистика с поиском
- 🛡️ **Кланы**: список, состав, лидер, описание с игровыми цветами
- ☢️ **Выбросы**: радар по всем регионам, живой таймер, тревога в навбаре
- 🔔 **Алерты в Telegram-боте**: «сообщи, когда Комета Обычная +10 будет дешевле 5кк»
  (колокольчик на странице предмета) и «начался выброс» (переключатель на странице выбросов).
  В мини-приложении пользователь определяется автоматически, в обычном браузере — кнопкой
  «Привязать Telegram» (одноразовая ссылка в бота → «✅ Привязать», без пароля).
  Проверку и рассылку делает бэкенд (`TELEGRAM_BOT_TOKEN`)
- ⭐ **Избранное и «Мой рынок»**: лучшие цены прямо на главной, синхронизация через
  Telegram CloudStorage, диплинки на любой экран

## Стек

- Next.js 16 (App Router), React 19, TypeScript
- TanStack Query
- CSS Modules
- WebGL (3D-аномалия на собственном шейдере, без three.js)
- Telegram Mini Apps SDK (грузится лениво, только внутри Telegram)

## Запуск

```bash
npm install
cp .env.example .env.local   # указать URL бэкенда
npm run dev
```

`npm run items` — пересобрать справочники из официальной базы EXBO
([stalcraft-database](https://github.com/EXBO-Studio/stalcraft-database)): предметы,
названия статистик и достижений, рецепты бартера. Запускать после обновлений игры.
Таблица пересоздания «блок → ресурсы» ведётся вручную в `scripts/packs.mjs`.

## Архитектура

```
src/
  app/            страницы (App Router)
  components/     Anomaly (WebGL), Shell (навбар/фон), PriceChart, LotFilters, Barter, ui/*
  features/       данные и хуки по доменам: auction, items, barter, character, clans, emission, meta
  lib/            api, store (useSyncExternalStore + localStorage + CloudStorage), telegram, format
scripts/          build-items.mjs, packs.mjs — сборка справочников
```

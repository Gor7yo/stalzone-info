# STALZONE INFO — Frontend

Telegram Mini App для просмотра информации о STALZONE через API.

## Возможности

- 🌍 Переключение регионов
- 🔨 Аукцион
- 👤 Поиск персонажей
- 🛡️ Информация о кланах
- ☢️ Информация о выбросах

## Стек

- Next.js
- React
- TypeScript
- MobX
- TanStack Query
- CSS Modules
- Telegram Mini Apps
